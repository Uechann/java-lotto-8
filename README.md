# java-lotto-precourse

## 기능 목록
## 1. 입력 및 검증 기능
로또 구매 가격, 당첨 번호, 보너스 번호 입력 기능을 구현한다.
- 세부 구현
  - 로또 구매 가격 입력 (1장의 가격은 1000원, 1000원 단위로 입력)
  - 당첨 번호 6개 입력 (번호는 1~45 사이, 중복되지 않은 숫자)
  - 보너스 번호 1개 입력 (번호는 1~45 사이)
- 예외 상황
  - 가격
    - 패턴 검증 + 숫자가 아니라면 예외 처리
    - 1000원 단위가 아니라면 예외 처리 -> 도메인 비즈니스 예외처리
    - 1장도 못사는 가격 0 이하라면 예외 처리 -> 도메인 비즈니스 예외처리
  - 당첨 번호
    - 패턴 검증 + 숫자가 아닌 경우 예외 처리
    - 당첨 번호가 0 이하, 45 초과라면 예외 처리
    - 당첨 번호가 중복된 숫자가 있다면 예외 처리 -> 도메인 비즈니스 예외 처리
    - 당첨 번호가 6개가 아니라면 예외 처리 -> 도메인 비즈니스 예외 처리
  - 보너스 번호
    - 패턴 검증 + 숫자 아니라면 예외처리
    - 보너스 번호가 0 이하, 45 초과라면 예외 처리
    - 당첨 번호와 중복 된다면 예외처리 -> 도메인 비즈니스 예외 처리
- 테스트 케이스
  - 가격
    - [x] 1000원 입력 -> 성공
    - [x] 10000원 입력 -> 성공
    - [x] "", " " -> 예외 : 빈칸 공백은 허용되지 않습니다.
    - [x] `0` -> 예외 : 0은 허용되지 않습니다.
    - [x] `-1` -> 예외 : 음수는 허용되지 않습니다.
    - [x] `asdf` (입력 숫자가 아닌 값) -> 예외 : 문자는 허용되지 않습니다.
    - [x] '1000j' -> 예외 : 문자는 허용되지 않습니다.
    - [x] 1234원 입력 -> 비즈니스 예외 : 1000원 단위여야 합니다.
  - 당첨 번호
    - [x] 당첨 번호가 `1,2,3,4,5,6` -> 성공
    - [x] 당첨 번호가 `,1,2,3,` -> 실패 : 패턴이 맞지 않습니다.
    - [x] 당첨 번호가 `ㅁ,ㅁ,ㅁ,ㅁ,ㅁ` -> 실패 : 당첨 번호는 숫자이어야 합니다.
    - [x] 당첨 번호가 `0,1,2,3,4,5` -> 실패 : 1~45 숫자이어야 합니다. -> 도메인
    - [x] 당첨 번호가 `1,2,3,4,5,5` -> 실패 : 당첨 번호가 중복 됩니다. -> 도메인
    - [x] 당첨 번호가 `1,2,3,4` -> 실패 : 당첨 번호는 6개 이어야 합니다. -> 도메인
  - 보너스 번호
    - [x] 보너스 번호가 `7` -> 성공
    - [x] 보너스 번호가 `ㅁ` -> 실패 : 보너스 번호는 숫자이어야 합니다.
    - [x] 보너스 번호가 `1,` -> 실패 : 패턴이 맞지 않습니다.
    - [x] 보너스 번호가 `0` -> 실패 : 보너스 번호는 1~45 숫자이어야 합니다. -> 도메인
    - [x] 보너스 번호가 `1` -> 실패 : 당첨 번호과 중복됩니다.

## 2. 로또 발행 기능
입력 받은 가격으로 해당 개수의 로또를 발행 하고 6개의 로또 번호들을 저장한다.
이때 로또 번호들은 오름차순으로 정렬 되어야 한다.

- 세부 구현
  - 로또 발행기
  - 로또 번호 생성기 -> 전략 패턴으로 어떤 방식으로 생성할지 추상화
  - 로또 번호 생성 후 정렬 후 저장 기능
- 테스트 케이스
  - 로또 발행기
    - [x] `8000`원 입력 -> 8개 로또 발행 -> 성공
  - 로또 번호 생성기
    - [x] `1,5,3,35,27,2` -> 성공
  - 로또 번호 정렬 후 저장 기능
    - [x] `1,5,3,35,27,2` -> `1,2,3,5,27,35` 저장-> 성공

## 3. 로또 당첨 발행 기능
발행된 로또들을 통해 당첨 번호와 보너스 번호와 비교하여 당첨 내역을 출력한다.
이때, 게임 룰 추상화를 적용하여 코드가 룰을 정하는 것이 아니고 룰이 코드를 지배하도록 구현하도록 하는 것이 목표이다.

- 세부 구현
  - 게임 룰 관리 기능
    - 전략 패턴으로 룰을 관리할 수 있도록 구현한다.
    - 등수, 당첨 기준, 금액을 커스텀 할 수 있도록 한다.
  - 당첨 내역 체크 기능
  - 당첨 내역 저장 기능
    - [등수, 당첨 기준, 금액, 개수]를 저장한다.
- 테스트 케이스
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,4,5,6` -> 6개 일치 -> 1등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,4,5,7` -> 5개 일치 보너스 일치 -> 2등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,4,5,8` -> 5개 일치 -> 3등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,4,8,9` -> 4개 일치 -> 4등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,7,8,9` -> 4개 일치 -> 4등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,3,8,9,10` -> 3개 일치 -> 5등 판별 -> 성공
  - [x] 당첨 번호 `1,2,3,4,5,6,7` 발행 번호 `1,2,7,8,9,10` -> 3개 일치 -> 5등 판별  -> 성공

## 4. 수익률 발행 기능

(총 당첨 금액 / 구매 가격) 을 통해 계산 후 소수점 둘째 자리에서 반올림 계산한다.
- 세부 구현
  - 수익률 계산기 클래스

- 테스트 케이스
  - [x] 구매 가격 `8000`원, 당첨 금액 `5000`원 -> `65.2` 반환
  - [x] 구매 가격 `8000`원, 당첨 금액 `0`원 -> `0` 반환

## 기능 요구 사항
간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
  - `범위 체크`
- 1개의 로또를 발행할 때 `중복되지 않는 6개의 숫자`를 뽑는다.
  - `중복 검사`, `로또 발행기` 구현
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
  - `보너스 번호 처리`
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등 : 6개 번호 일치                 / 2,000,000,000원
  - 2등 : 5개 번호 일치 + 보너스 번호 일치  / 30,000,000원
  - 3등 : 5개 번호 일치                 / 1,500,000원
  - 4등 : 4개 번호 일치                 / 50,000원
  - 5등 : 3개 번호 일치                 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
  - `구매 금액 -> 로또 발행기`
- 로또 한장의 가격은 1,000원이다.
  - 로또 한장 가격 상수화 
- 당첨 번호와 보너스 번호를 입력받는다.
  - `InputView 구현`
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
  - `OutputView 구현`, `번호 비교 기능`, `수익률 계산 기능`
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 예외를 발생시키고, 
  "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다..
  - `예외 처리`
  - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

## 입출력 요구 사항
입력
- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
```
14000
```
- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

```
1,2,3,4,5,6
```
- 보너스 번호를 입력 받는다.
```
7
```

출력
- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

- 당첨 내역을 출력한다.

```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

```
총 수익률은 62.5%입니다.
```

예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
```
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 프로그래밍 요구 사항
- 함수의 길이가 15라인 을 넘지 않도록 구현한다.
- 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- else 예약어를 사용하지 않는다.
- Java `Enum`을 적용하여 프로그램을 구현한다.
- 구햔한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.in, System.out)와 관련된 로직은 제외한다.
